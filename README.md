# Space Bounce
We did a game based on the premise "Bounce", this game is about an astronout squirriel that explores around destroyed spaceships and ruins
to find the easter eggs on the 2 levels(the face of some of the orgs), and recolect the trophy at the end of the level
# Controls
**THE CONTROLS ARE INVERTED ON PURPOSE!!!**

A= Right
D= Left
Space/W= Jump
